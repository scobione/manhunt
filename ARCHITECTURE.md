# MANHUNT integration contract
Client: React Vite on port 5173. API Express+Socket.IO port 3001; Vite proxies /api and /socket.io. Shared types in shared/types.ts are authoritative.
Authentication: Supabase Google OAuth access token as Authorization Bearer and socket auth.token. No guest or fake identity in production. Explicit NODE_ENV=test + TEST_AUTH=true test-only tokens of form test:<uuid>:<username>, restricted to tests. Never enable in production.
REST endpoints: GET /api/health public; GET /api/config public gives {configured:boolean, authConfigured:boolean, pushPublicKey?:string}; GET/PATCH/DELETE /api/profile; GET /api/social returns {friends:Profile[],requests:...,notifications:...,blocked:Profile[]}; POST /api/friends/request {code}; POST /api/friends/respond {requestId,accept}; DELETE /api/friends/:id; POST/DELETE /api/blocks/:id; POST /api/invites {friendId,code}; PATCH /api/notifications/:id; GET /api/history; GET/POST /api/presets. Frontend may call Supabase Storage directly with user session and RLS for avatars.
Socket ack {ok:true,data?:...} or {ok:false,error:string}. events lobby:create {settings?:Settings}, lobby:join {code}, lobby:sync {}, lobby:command {command:Command}; server sends lobby:state (LobbyView), social:changed {}, notice {message}. One active lobby per user. Backend holds Engine instance and serializes mutations through persistence queue. Engine API agreed directly with backend agent.
Database: Supabase migrations plus repository persistence. Coordinate SQL/API expectations between backend+DB agent. No live GPS persisted in profile or public table. All private engine checkpoints service-role-only; user snapshots filtered before sending.
Map: MapLibre raster OSM visible only (no bulk prefetch); zone GeoJSON + Turf. Actual geolocation only on explicit consent. No fake players/stats in app. Standalone unconfigured app shows honest setup-needed state while mode rules, editor and safety/privacy pages work.
